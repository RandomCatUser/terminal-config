⬇️ download zip 🐱 view on github

fastfetch — the braille cat, pre-tinted pink → violet

oh-my-posh prompt — blue, pink and lavender, local theme, no network needed

── what it does

runs install.bat and it asks before it touches anything — every piece is a y / n question, and n cleanly skips that piece

offers JetBrainsMono Nerd Font first — downloaded from the nerd-fonts release and installed per-user, no admin window

offers oh-my-posh via winget, then deploys the Catppuccin Mocha theme locally and points every PowerShell profile at the local file — works offline

restyles Windows Terminal — Mocha colors, JBM NFM 10pt, acrylic glass at 80% — and leaves a settings.json.bak for the undo

deploys fastfetch config + the tinted cat logo, hash-checks everything, rewrites nothing that already matches, then runs fastfetch as your “it worked” moment

── quick start

double-click install.bat, or from a terminal:

❯ powershell -ExecutionPolicy Bypass -File install.ps1

want a different logo? point regen-logo.ps1 at your own braille art, run it, rerun the installer.
