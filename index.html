02install
  1. 01

    double-click install.bat — it handles execution policy, and every piece starts with a y / n question. saying no skips that piece cleanly.

  2. 02

    JetBrainsMono Nerd Font — checked first; downloads from the nerd-fonts release and installs per-user, no admin window.

  3. 03

    oh-my-posh + the theme — winget installs the engine, the Mocha theme lands on disk, every PowerShell profile points at the local file. it also offers to restyle Windows Terminal (Mocha scheme, JBM NFM 10pt, acrylic 80%) and leaves a settings.json.bak for the undo.

  4. 04

    fastfetch — config + the tinted cat deploy to %USERPROFILE%\.config\fastfetch, then fastfetch runs right in front of you. that's the "it worked" moment.

❯ more of a manual type? powershell -ExecutionPolicy Bypass -File install.ps1
❯ rerun it any time — files are hash-checked, and things that already match report as unchanged.
